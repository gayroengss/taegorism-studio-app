# Taegorism Studio (데스크톱 앱)

강의 영상으로 자막·요점·카드뉴스·PPT·쇼츠·자막 입힌 영상을 만드는 태고리즘 스튜디오를 **내 컴퓨터에 설치해서** 쓰는 앱입니다. 로그인 없이 쓰고, 강의 자료는 내 컴퓨터에만 저장됩니다.

> 이 앱은 아직 개발자 서명이 없어서, 처음 한 번 "확인되지 않은 앱"이라는 경고가 뜹니다. 정상이에요. 아래 설치 방법대로 한 번만 허용하면 됩니다.

## 내려받기
이 저장소 오른쪽의 **Releases** 에서 가장 위(최신) 버전을 열고, 아래 **Assets** 에서 내 컴퓨터에 맞는 파일을 받으세요.
- 맥(애플 칩 M1 이후, macOS 13 이상): 이름이 `.dmg` 로 끝나는 파일. 인텔 맥용은 아직 없습니다.
- 윈도우(64비트, 윈도우 10 (1903 업데이트) 이상): 이름에 `Setup` 이 들어간 `.exe` 파일. 오래되거나 저가형인 CPU(셀러론·펜티엄 N 시리즈 등)에서도 돌지만 자막 만들기가 아주 느릴 수 있습니다.

## 설치
### 맥
1. `.dmg` 를 열고 **Taegorism Studio** 를 **응용 프로그램** 폴더로 끌어다 놓습니다. **꼭 응용 프로그램 폴더로 옮긴 뒤 거기서 여세요** — dmg 창이나 다운로드 폴더에서 바로 열면 자막 만들기(음성 인식)가 동작하지 않습니다.
2. 응용 프로그램 폴더에서 열면 경고가 뜹니다. **완료**(또는 **확인**)를 눌러 닫습니다. **휴지통으로 이동** 은 누르지 마세요.
3. **시스템 설정 → 개인정보 보호 및 보안** 을 열고 아래쪽으로 내려가 **그래도 열기** 를 누릅니다. 암호를 물으면 맥 암호를 넣고, 다시 나온 창에서 **열기** 를 누릅니다(처음 한 번만).

### 윈도우
1. 브라우저가 내려받은 파일을 막으면 내려받기 목록에서 그 파일의 `…` → **유지** → **그래도 유지** 를 누릅니다.
2. `Setup` 이 들어간 `.exe` 를 실행합니다.
3. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누릅니다(처음 한 번만).
4. 설치 범위(나만 사용 / 모든 사용자)와 설치 위치를 고르고 설치합니다. 바탕화면에 바로가기가 생깁니다.

## 처음 쓸 때
1. 앱을 열고 위쪽 메뉴의 **설정** 에서 **음성 인식 모델 받기 (약 1.1GB)** 를 누릅니다. 한 번만 받으면 됩니다(받는 동안 인터넷이 필요하고, 디스크에 2GB 이상 여유가 있어야 합니다). 받다가 끊겨도 다시 누르면 이어서 받습니다.
   - 자막은 **이 컴퓨터에서** 만듭니다. 걸리는 시간은 컴퓨터마다 크게 다릅니다. 설정 화면의 음성 인식 칸에 **그래픽 칩 사용** 이라고 나오면 빠르고, **CPU 사용** 이라고 나오면 느립니다(자막을 한 번 만든 뒤에 나옵니다).
     - 맥(애플 칩): 1시간 강의에 약 12~16분(M5 맥에서 잰 값이고, 더 오래된 칩은 더 걸릴 수 있습니다). 설치하거나 업데이트한 뒤 처음 한 번은 30초쯤 더 걸립니다.
     - 윈도우: 그래픽 칩이 도와 주는 컴퓨터는 빠를 것으로 보이지만 아직 재 보지 못했습니다. 그래픽 칩 없이 CPU 로만 돌면 느립니다 — 보통 노트북(8스레드)은 강의 1시간에 1~1.5시간 정도로 짐작하고, 성능이 낮은 컴퓨터(2스레드짜리 시험용 컴퓨터)에서는 3분 소리에 약 12분, 1시간 강의에 약 4시간이 걸렸습니다.
   - 메모리 8GB 컴퓨터는 자막을 만드는 동안 다른 프로그램을 닫아 주세요.
   - 자막은 2분 조각마다 저장됩니다. 도중에 앱을 닫아도 같은 영상 파일을 다시 고르면 이어서 만듭니다.
2. **Gemini API 키** 를 넣고 **저장** 을 누릅니다(요점·카드뉴스·쇼츠 추천에 씁니다. 자막에는 필요 없어요). 키는 https://aistudio.google.com/apikey 에서 무료로 받을 수 있어요.
3. (선택) 카드뉴스에 무료 사진을 넣으려면 **Pexels API 키** 도 넣습니다. https://www.pexels.com/api/ 에서 받습니다. 넣지 않으면 사진 넣기 버튼이 보이지 않습니다.
4. 위쪽 메뉴의 **새 강의** 에서 영상 파일을 고르면 시작합니다.

Gemini 무료 키는 하루에 쓸 수 있는 양이 정해져 있습니다. 한도에 걸리면 앱이 알려 주니, 그때는 잠시 뒤나 다음 날 다시 해 보세요. 자막은 이 컴퓨터에서 만들어서 이 한도와 상관없습니다.

## 알아둘 것
- **영상 파일은 내 컴퓨터 밖으로 나가지 않습니다. 자막을 만들 때는 소리가 컴퓨터 밖으로 나가지 않습니다**(원고를 넣어도 마찬가지). 구글 Gemini 로 가는 것은 요점·카드뉴스·쇼츠 추천을 만들 때의 자막 글과 카드뉴스 초안뿐입니다(카드뉴스 참고 이미지를 고르면 그 이미지도). 사진을 찾을 때는 검색어가 Pexels 로 갑니다.
- 그래서 인터넷은 음성 인식 모델을 처음 받을 때, Gemini·Pexels 를 쓸 때, PPT 탭에서 NotebookLM 사이트를 열 때 필요합니다. 카드에 넣은 Pexels 사진도 인터넷에서 불러오므로, 인터넷이 있어야 보이고 PNG 로 저장됩니다.
- 강의 자료와 키가 저장되는 폴더: 맥 `~/Library/Application Support/Taegorism Studio`, 윈도우 `%APPDATA%\Taegorism Studio`. 앱을 지워도 이 폴더는 남습니다.
  - 여는 법: 맥은 Finder 에서 **이동 › 폴더로 이동**(⌘⇧G)을 누르고 위 경로를 붙여 넣습니다. 윈도우는 **Windows 키+R** 을 누르고 `%APPDATA%\Taegorism Studio` 를 넣습니다.
- 문제가 있으면 위 폴더의 `server.log` 를 보내 주세요. 같은 폴더의 `settings.json` 에는 내 API 키가 들어 있으니 **보내지 마세요.**
